# Answer key — Task 01 (Should you even run an experiment?)

**Instructor-facing.** Grades reasoning; many decisions are valid.

## Model answer (shape)

A strong card names a **causal** decision with a real owner, shows the outcomes
lead to **different** actions, and gives an honest three-period cost. Example:
"Should we move the newsletter signup above the fold? → if it lifts signups
without hurting scroll-depth we ship; if it hurts the guardrail we don't. Causal;
reversible; running cost = a worse layout for half of users for two weeks."

## Common mistakes

- **A predictive question in disguise** ("which users will churn?") — no
  intervention, no experiment.
- **All roads lead to ship** — if every outcome triggers the same action, the
  test is decoration.
- **Testing the already-obvious** — a legal/physical certainty (cookie-consent
  symmetry, a required disclosure).
- Listing only the running cost and ignoring planning + opportunity cost.

## Excellent looks like

The "needs an experiment because ___" sentence names a genuine, reversible,
decision-changing question, and the "depends on" is a real stake or ethical line —
not "we'd learn something."
