# Solutions — instructor material

> **Keep this private if the pack is published to students.** This folder holds
> answer keys and the fully-worked demo notebooks. If `course-pack/` becomes a
> public student repository, move `solutions/` to a private repo or a private
> branch, or delete it before publishing.

## What's here

- **`solution-01.md` … `solution-11.md`** — answer keys for the weekly tasks:
  a model answer, common mistakes, and what an "excellent" submission shows.
  They grade **reasoning**, so they describe strong answers rather than a single
  correct string — most tasks have many good answers.
- **`*-demo.ipynb`** — the worked versions of the exercise notebooks. Every
  demo runs top to bottom and matches the numbers quoted in its "Without code"
  section. The exercise notebooks' spoiler cells contain the same solution code.

## Using the keys

Each task is marked on three things, restated per task:

1. Did they answer the actual question, not an easier nearby one?
2. Did they name what the answer **depends on** — the trade-off, threat, or constraint?
3. Were they honest about what it does **not** yet settle?

A confident, well-reasoned answer that differs from the model answer can score
full marks. A tidy answer that dodges the real question does not.
